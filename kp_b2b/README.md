# Страница «Корпоративное предложение (B2B)»

## Как добавить на сайт (Streamlit)

1. Скопируйте в корень репозитория сайта:
   - папку `kp_b2b/` (логика, шаблон, логотип, шрифты);
   - файл `data/menu.xlsx` (меню и цены);
   - файл `pages/КП_B2B.py` (сама страница).
   Если в проекте уже есть папка `pages`, просто положите файл туда.
   Если меню сайта собирается через `st.navigation`, добавьте
   `st.Page("pages/КП_B2B.py", title="КП для B2B", icon="🍕")`.
2. Допишите в `requirements.txt` строки из этого `requirements.txt`.
3. Положите в корень репозитория `packages.txt` (если он уже есть — добавьте строки).
   Это системные библиотеки для сборки PDF на Streamlit Cloud.
4. Сделайте commit/push — Streamlit Cloud пересоберёт приложение сам.

Проверить локально: `pip install -r requirements.txt` и `streamlit run app.py` (главный файл проекта).

## Как обновлять цены
Замените `data/menu.xlsx` новым файлом того же формата (листы «Пиццы» и «Остальное меню»).
Разово можно загрузить свежее меню прямо на странице — «Меню и цены».

## Что где настраивается (kp_b2b/core.py)
- `TIER_TEMPLATES` — составы шаблонов Базовый / Оптимальный / Премиальный (пицца → доля);
- `SPICY` — пиццы, у которых в КП рисуется перчик;
- `DEFAULT_FOOTER` — текст внизу КП.
